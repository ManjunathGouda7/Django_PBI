3. GIT COMMANDS USED TO INITIALIZE AND PUSH REPOSITORY
--------------------------------------------------------------------------------
# Initialize Git repository
git init

# Configure remote origin
git remote add origin https://github.com/ManjunathGouda7/Django_PBI.git

# Set main branch
git branch -M main

# Stage and commit all files
git add .
git commit -m "Initial commit: Production Power BI Telemetry Analytics Platform with DRF, MongoDB Ingestion, Authentication, and Interactive Scatter Engine"

# Push to GitHub main branch
git push -u origin main


4. HOW TO RUN THE PLATFORM LOCALLY
--------------------------------------------------------------------------------
1. Activate virtual environment:
   d:\Manju\PowerBI_Django\mgenv\Scripts\activate

2. Run Django migrations:
   python manage.py migrate

3. Launch development server:
   python manage.py runserver 0.0.0.0:8000

4. Access Web Applications:
   - Main Studio App : http://127.0.0.1:8000/
   - Login Portal    : http://127.0.0.1:8000/login/
   - Swagger API Docs: http://127.0.0.1:8000/api/swagger/
