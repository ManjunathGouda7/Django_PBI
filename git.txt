2. STEP-BY-STEP GUIDE: HOW WE CREATED, SWITCHED & PUSHED TO 'Subbranch'
--------------------------------------------------------------------------------
Step 1: Check current repository status and branches
  $ git status
  $ git branch -a

Step 2: Create new local branch 'Subbranch' and switch to it immediately
  $ git checkout -b Subbranch

Step 3: Stage all modified source files, new modules, and configuration files
  $ git add .

Step 4: Commit staged changes with descriptive enterprise commit message
  $ git commit -m "feat: Add AI Auto-Dashboard Builder, Data Wrangling, Multi-Page Excel Export, Multi-Dataset Joins, and Kiosk Presentation Mode"

Step 5: Push 'Subbranch' to GitHub and set up remote upstream tracking
  $ git push -u origin Subbranch

Step 6: Switch between branches in the future
  - To switch to Subbranch:
      $ git checkout Subbranch
  - To switch back to main:
      $ git checkout main
  - To sync & pull latest changes from Subbranch:
      $ git pull origin Subbranch
